CipherLab RS51_HS — Barcode Test Sheet

Code 128 barcodes for validating offline test mode & Receive Lot No. (scanner-test APK)

ข้อควรจำก่อนทดสอบ:
1. ตรวจสอบว่าแอปมีแถบสีแดง โหมดทดสอบ — ไม่มีการบันทึกข้อมูล ที่ด้านบนสุดของหน้า รับเข้า / ปล่อยออก
2. ตั้งค่า ReaderConfig บน RS51: Profile ผูกกับ com.cipherlab.scanbarcodeapp, โหมด Keyboard Emulation (KeyEvent), Delay 0 ms
3. หน้า Receive: ต้องเลือก Lot No. ด้านบนก่อนเริ่มสแกน
1. TEST001 (Auto Mode)
สแกนขณะ Auto เปิดอยู่ → บันทึกสำเร็จอัตโนมัติ (~150 ms) เสียง Air
2. TEST002 (Auto Mode)
สแกนต่อเนื่อง → เคลียร์ช่อง input และ refocus ทันที
3. TEST003 (Auto Mode)
สแกนต่อเนื่อง → เพิ่มเข้าประวัติการสแกน
4. TEST004 (Auto Mode)
สแกนต่อเนื่อง → ไม่ต้องกด Enter หรือแตะจอ
5. TEST005 (Auto Mode)
สแกนรหัสที่ 5 → ครบชุดสแกนปกติ Auto ON
6. TESTD01 (Lot Match)
สแกนเมื่อเลือก Lot ตรง → บันทึกสำเร็จปกติ
7. TESTD02 (Lot Mismatch → Change Lot)
สแกนเมื่อเลือก Lot ไม่ตรง → เด้ง Modal ยืนยันเปลี่ยน Lot (Lot เดิม: TEST-LOT-RECEIVE-001)
8. DUP001 (Duplicate Test)
สแกน 2 ครั้ง → ครั้งที่ 2 ต้องเด้ง Modal สีแดง: "รายการนี้ถูกสแกนแล้ว"
9. INVALID001 (Invalid Test)
สแกน → ต้องเด้ง Modal สีแดง: "เลขนี้ไม่ถูกต้อง" ต้องกด ยืนยัน เท่านั้น
10. SYSTEM001 (System Error Test)
สแกน → ต้องเด้ง Modal: "ไม่สามารถตรวจสอบรายการได้"
11. TEST006 (Enter Suffix Test)
เปิด Enter suffix ใน ReaderConfig แล้วสแกน → ต้องบันทึกครั้งเดียว ห้ามส่งซ้ำ
12. MANUAL001 (Auto Off Test)
ปิดสวิตช์ Auto → สแกนต้องไม่ส่งอัตโนมัติ ต้องกดยืนยัน/Manual
